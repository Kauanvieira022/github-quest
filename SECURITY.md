# Política de Segurança

## Versões cobertas

O GitHub Quest ainda está em desenvolvimento inicial. Correções de segurança
são aplicadas somente à versão mais recente da branch `main`.

## Como relatar uma vulnerabilidade

Não abra uma Issue pública com detalhes que permitam explorar o problema.

1. Acesse a aba **Security** do repositório.
2. Se a opção **Report a vulnerability** estiver disponível, envie o relato por
   esse canal privado.
3. Caso a opção não esteja disponível, procure um canal privado indicado no
   perfil do mantenedor no GitHub.

Inclua, quando possível:

- descrição do impacto;
- passos mínimos para reproduzir;
- versão, commit ou URL afetada;
- evidências sem dados pessoais ou segredos;
- sugestão de correção, se houver.

O mantenedor avaliará o relato, combinará uma forma segura de acompanhamento e
evitará divulgar detalhes antes que exista uma correção.
