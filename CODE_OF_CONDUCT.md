# Código de Conduta

O GitHub Quest busca ser um espaço acolhedor para aprender, perguntar, revisar
e contribuir.

## Comportamentos esperados

- Trate dúvidas e erros como oportunidades de aprendizado.
- Faça críticas ao trabalho, nunca à pessoa.
- Explique decisões com contexto e respeito.
- Reconheça contribuições e dê crédito de forma honesta.
- Respeite diferentes níveis de experiência, identidades e perspectivas.
- Evite expor dados pessoais ou conversas privadas.

## Comportamentos inaceitáveis

- Assédio, intimidação, discriminação ou ataques pessoais.
- Linguagem sexualizada, ameaças ou incentivo à violência.
- Divulgação de informações privadas sem autorização.
- Spam, manipulação de métricas ou contribuições deliberadamente enganosas.
- Qualquer conduta que torne a participação insegura ou hostil.

## Aplicação

Os mantenedores podem editar ou remover conteúdo, encerrar interações e limitar
a participação quando este código não for respeitado. As decisões devem
considerar contexto, impacto e recorrência.

Para relatar uma situação que não possa ser tratada publicamente, não abra uma
Issue com dados pessoais. Procure um canal privado indicado no perfil do
mantenedor no GitHub.

Este código se aplica ao repositório, às revisões, às discussões relacionadas ao
projeto e a espaços públicos em que alguém represente oficialmente o GitHub
Quest.
